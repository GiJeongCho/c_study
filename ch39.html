이미지 AI 변천사 — CNN·YOLO·ViT·멀티모달

1998년 LeNet-5가 손글씨를 읽기 시작한 뒤 25년 만에, 비전 모델은 "픽셀을 분류"하는 수준을 넘어 "이미지와 글을 함께 이해하는" 멀티모달 추론까지 왔습니다. 이 장은 CNN → ResNet → YOLO → ViT → CLIP → Diffusion → GPT-4V/Claude Vision으로 이어진 흐름을 핵심 아이디어 중심으로 훑고, 금융 KYC·공시 OCR·차트 인식·대시보드 스크린샷 분석처럼 하나증권 퀀트/OMS에서 쓸만한 활용을 정리합니다.

이 장에서 배울 것

  • 왜 Fully Connected가 아니라 CNN이 이미지에 맞는가 (locality · parameter sharing · translation invariance)
  • CNN 이정표: LeNet → AlexNet → VGG → Inception → ResNet → EfficientNet
  • 분류·로컬라이제이션·디텍션·세그멘테이션의 차이와 평가지표(IoU·mAP)
  • Object Detection 변천: R-CNN 계열(2-stage) → YOLO 계열(1-stage, v1~v11)
  • Vision Transformer(ViT) — Transformer가 비전에도 통한다
  • CLIP — 이미지와 텍스트를 같은 공간에 임베딩
  • Diffusion — DALL·E, Stable Diffusion, Midjourney의 생성 메커니즘
  • SAM(Segment Anything), DINOv2, 멀티모달 LLM(GPT-4V·Claude Vision·Gemini)
  • 금융/OMS 활용: eKYC OCR, 공시 PDF, 차트 패턴, 대시보드 스크린샷 이상감지

39-1CNN 기초와 역사의 이정표

왜 FC가 아니라 CNN인가 — 이미지의 세 가지 "특성"

256×256 컬러 이미지는 픽셀이 256·256·3 = 196,608개입니다. 이걸 그대로 Fully Connected(완전연결) 신경망에 넣으면 첫 층 하나에 수십억 개의 가중치가 필요합니다. 메모리도 메모리지만, 더 큰 문제는 "이미지의 성질"을 전혀 활용하지 못한다는 겁니다.

CNN(Convolutional Neural Network)은 이미지가 가진 세 가지 특성을 그대로 모델 구조에 녹였습니다.

  • Locality(지역성): 고양이 눈은 주변 몇 픽셀 안에서 결정된다. 멀리 떨어진 픽셀은 거의 무관.
  • Translation invariance(평행이동 불변성): 고양이가 왼쪽 위에 있든 오른쪽 아래에 있든 고양이다.
  • Parameter sharing(파라미터 공유): 같은 "에지 검출기" 필터를 이미지 전체에 재사용 → 가중치가 수십 억에서 수천 개로 급감.

CNN의 기본 블록: Conv → ReLU → Pooling을 반복해 "저수준 특징(에지) → 중간 특징(텍스처) → 고수준 특징(얼굴·고양이·BMW 로고)"로 추상화합니다. 마지막엔 FC로 분류 결과를 뽑습니다.

용어 미리 정리

  • Stride: 필터가 몇 픽셀씩 미끄러지는가. 2면 출력 크기가 절반.
  • Padding: 가장자리에 0을 둘러 출력 크기 유지. 'same' padding이 대표.
  • Pooling: 2×2 영역에서 최댓값(MaxPool)이나 평균을 뽑아 공간을 축소. 평행이동 불변성 강화.
  • Receptive field: 뒤쪽 뉴런 하나가 입력에서 "보는" 영역. 층이 깊어질수록 커진다.
  • Feature map: 하나의 필터가 입력 전체에 적용된 결과. CNN은 수십~수백 개의 feature map을 동시에 만든다.

ResNet의 결정적 아이디어 — 잔차연결

층을 많이 쌓으면 성능이 좋아져야 할 것 같지만, 2015년 전까지는 20층을 넘기면 오히려 정확도가 떨어졌습니다(기울기 소실·학습 붕괴). ResNet은 아주 간단한 트릭 하나로 이 벽을 깼습니다.

39-2Object Detection·Segmentation과 YOLO 변천사

네 가지 비전 태스크 — 뭐가 다른가

태스크출력평가지표대표 모델

IoU와 mAP

  • IoU (Intersection over Union): 예측 박스 ∩ 정답 박스 / 예측 ∪ 정답. 1에 가까울수록 완벽.
  • AP (Average Precision): Precision-Recall 커브 아래 면적. 클래스별로 계산.
  • mAP: 전체 클래스의 AP 평균. mAP@0.5는 IoU 임계 0.5 기준, mAP@0.5:0.95는 0.5~0.95를 평균(더 엄격).

Object Detection 변천 — 2-stage에서 1-stage로

디텍션은 "어디에 뭐가 있나"를 함께 맞혀야 합니다. 두 가지 접근이 경쟁해 왔습니다.

YOLO 10년 — v1부터 v11까지

YOLO(You Only Look Once)는 2015년 Joseph Redmon의 "이미지를 한 번만 CNN에 통과시켜 모든 박스와 클래스를 동시에 뱉자"는 아이디어에서 출발했습니다. 그 뒤 Ultralytics·여러 그룹이 바통을 이어받아 지금은 산업계 디텍션의 사실상 표준이 되었습니다.

YOLO 라이선스

Ultralytics YOLOv5/v8/v11은 AGPL-3.0입니다. 사내 서비스에 넣으면 소스 공개 의무가 걸릴 수 있습니다. 상용으로 쓰려면 Ultralytics 상용 라이선스를 구매하거나, Apache/MIT 라이선스 모델(예: 일부 YOLOv7 포크, RT-DETR 등)을 선택해야 합니다. 금융권 사내 PoC에서 자주 간과되는 포인트입니다.

Segmentation과 그 외 비전 태스크

  • U-Net (2015): 의료영상 세그멘테이션의 표준. 수축-확장(encoder-decoder) 구조 + skip connection. 세포·장기 분할, 그리고 요즘은 Diffusion 모델의 핵심 백본으로도 재등장.
  • Mask R-CNN (2017): Faster R-CNN에 마스크 브랜치를 추가해 Instance Segmentation.
  • DeepLab v3+: Atrous Convolution으로 넓은 receptive field. 자율주행 도로/차선 세그.
  • Pose Estimation: OpenPose, MediaPipe. 사람 관절 좌표 추출.
  • OCR: CRNN(2015) → Tesseract → TrOCR(2021, Transformer 기반) → 멀티모달 LLM이 직접 텍스트 뽑는 2024~.

39-3ViT·CLIP·Diffusion·멀티모달 LLM과 금융/OMS 활용

Vision Transformer (ViT) — Transformer가 비전에도 통한다

2020년, Google은 "이미지를 16×16 패치로 쪼개 Transformer에 그냥 넣으면 안 될까?"라는 다소 황당한 질문을 던졌습니다. 결과는 충격이었습니다. 충분한 데이터(JFT-300M)만 있으면 ResNet을 넘어섰습니다.

CLIP — 이미지와 텍스트를 같은 공간에

2021년 OpenAI는 "인터넷에서 긁은 (이미지, 캡션) 4억 쌍"으로 이미지 인코더와 텍스트 인코더를 함께 학습했습니다. 둘의 임베딩이 "같은 의미면 가깝고 다르면 멀도록" 대조학습(contrastive learning). 결과물이 CLIP입니다.

CLIP이 바꾼 것: (1) 라벨 없이 자연어 설명만으로 "zero-shot 분류" 가능 → 사내 데이터 라벨링 비용 급감, (2) Stable Diffusion·DALL·E 같은 생성 모델의 "텍스트 가이던스" 기반, (3) 멀티모달 검색(이미지로 텍스트 찾기·텍스트로 이미지 찾기).

Diffusion — DALL·E, Stable Diffusion, Midjourney의 메커니즘

GAN이 "두 네트워크가 겨루며" 그림을 만들었다면, Diffusion은 더 단순한 아이디어입니다: 이미지에 노이즈를 조금씩 끼얹어 완전한 가우시안 노이즈로 만들었다가, 그 과정을 거꾸로 학습해 노이즈에서 이미지를 복원합니다. 추론 때는 "순수 노이즈"에서 시작해 수십 단계에 걸쳐 깨끗한 이미지로 디노이징합니다.

SAM · DINOv2 · 멀티모달 LLM — 2023~ 비전의 재편

  • SAM (Segment Anything Model, Meta 2023): "아무 이미지의 아무 객체도" 점 하나 찍으면 세그멘테이션. 1,100만 이미지·11억 마스크로 학습된 범용 세그 모델. 2024년 SAM 2로 비디오·실시간까지 확장.
  • DINOv2 / DINOv3: Self-supervised 비전 백본. 라벨 없이 수억 이미지로 학습 → 뽑은 특징이 분류·검색·세그 어디에나 잘 됨. ViT 기반.
  • 멀티모달 LLM: GPT-4V(2023), Claude 3/4 Vision, Gemini, Qwen2-VL. 이미지를 토큰화해 LLM에 넣고 "이 차트에서 뭐가 이상한가?"처럼 자연어로 묻고 답한다. 이미지 OCR·차트 해석·대시보드 분석을 사실상 "그냥 LLM"으로 할 수 있게 되었다.
  • Video 생성: Sora(OpenAI), Veo(Google), Kling, Runway. Diffusion + Transformer 결합.
  • Edge/모바일: YOLOv11n, MobileSAM, EfficientViT. 수십 MB로 실시간 추론.

"백본"의 선택지

  • 실시간 디텍션: YOLOv11, RT-DETR
  • 정확도 중심 분류·특징 추출: DINOv2/v3, ViT-L
  • 세그멘테이션(제로샷): SAM 2
  • 텍스트 가이드가 필요한 모든 것: CLIP 임베딩
  • 자연어로 이미지 이해·설명: GPT-5 Vision, Claude Opus 4.7, Gemini 2.5 멀티모달
  • 이미지 생성: SDXL, FLUX, DALL·E 3

금융권 비전 AI 체크리스트

  • 민감정보 유출: 신분증·여권·수표 이미지는 외부 API 금지. 사내 모델 또는 사내 LLM만.
  • 차별·편향: 얼굴 인식·행동 감지는 인종·성별 편향 리스크. 공정성 테스트 필수.
  • 생성 AI 위변조: 2025년 현재 Deepfake로 신분증 사진·셀카가 생성 가능. 라이브니스 검출(눈 깜빡임·3D 깊이)·신분증 PKI 검증 필수.
  • 적대적 공격: 패치 몇 픽셀로 YOLO가 사람을 못 보게 만들 수 있다(adversarial patch). 중요 결정엔 사람 확인.
  • GPU 자원: 대형 비전 모델은 CPU로 느리다. 사내 GPU 큐·배치 설계 필요.
  • YOLO 라이선스: Ultralytics 상용 라이선스 또는 Apache/MIT 대안 모델 검토.

  1. YOLOv11 + 포즈 검출(또는 Fall Detection 모델). 실시간이 중요하니 1-stage. 엣지 디바이스면 nano 버전.
  2. LayoutLM/Donut 또는 멀티모달 LLM(Claude Vision/GPT-5 Vision). 멀티모달 LLM이 가장 빠르고 정확하지만 비용·보안을 고려해 민감 리포트는 사내 모델 우선.
  3. 사내 CRNN/TrOCR + 라이브니스 검출. 외부 API 금지. 멀티모달 LLM 직접 호출은 민감정보 유출 리스크.
  4. CLIP 임베딩 유사도 또는 YOLO 파인튜닝. 로고가 적으면 CLIP zero-shot, 많거나 정확도 중요하면 YOLO 파인튜닝.
  5. 멀티모달 LLM(Claude Vision). 보고서 포맷 지정 + "참고 자료 내에서만" 원칙 적용. 결과는 사람 검토.

핵심 원칙: (1) 민감정보는 사내 모델, (2) 실시간엔 YOLO, (3) 라벨 없거나 적으면 CLIP zero-shot, (4) 보고서·설명 생성엔 멀티모달 LLM.

핵심 정리

  • CNN은 locality · translation invariance · parameter sharing을 모델 구조에 녹였다. 그래서 FC보다 압도적으로 효율적.
  • Conv → ReLU → Pool 반복 → 저수준(에지)에서 고수준(얼굴·로고)으로 특징이 추상화된다.
  • 이정표: LeNet(1998) → AlexNet(2012·딥러닝 겨울 종결) → VGG → Inception → ResNet(잔차연결) → EfficientNet → ConvNeXt.
  • ResNet의 잔차연결 F(x) + x는 150+층 학습을 가능하게 했고, Transformer 블록에도 그대로 쓰인다.
  • 비전 태스크 네 가지: 분류·로컬라이제이션·디텍션·세그멘테이션. 지표: Accuracy·IoU·mAP·mIoU.
  • 디텍션은 2-stage(Faster R-CNN, 정확) vs 1-stage(YOLO·SSD, 빠름). 산업계는 YOLO가 사실상 표준.
  • YOLO는 v1(2015) → v11(2024/25)까지 10년, 지금은 anchor-free·NMS-free·범용 비전 플랫폼으로 진화.
  • ViT(2020)는 "이미지를 패치 시퀀스"로 보고 Transformer를 그대로 적용. 데이터가 많으면 CNN보다 유리.
  • CLIP(2021)은 이미지·텍스트를 공유 임베딩 공간에. Zero-shot 분류·Stable Diffusion의 기반.
  • Diffusion은 "노이즈에서 이미지로 역확산". DALL·E 3·Stable Diffusion·Midjourney·Sora의 공통 패러다임.
  • SAM(2023·2024)은 "아무 객체도" 제로샷 세그. DINOv2/v3는 라벨 없는 범용 비전 백본.
  • 2024~ 멀티모달 LLM(GPT-5V, Claude Vision, Gemini)이 OCR·차트 해석·대시보드 분석을 자연어로 처리.
  • 금융/OMS 활용: eKYC, 공시 PDF, 차트 패턴, 위성 대안데이터, 로고 모니터링, OMS 대시보드 스크린샷 분석.
  • 체크리스트: 민감정보 사내 처리 · Deepfake 대응(라이브니스) · YOLO 라이선스(AGPL) · 적대적 공격 · 사람 검토.

면접 질문

자주 나오는 질문

Q1. 왜 FC가 아닌 CNN을 이미지에 쓰나요?

세 가지 때문입니다. (1) Locality: 이미지의 의미는 지역적 패턴에서 나오므로 작은 필터로 충분. (2) Translation invariance: 같은 필터를 전체에 적용하면 객체 위치가 바뀌어도 같은 특징이 잡힘. (3) Parameter sharing: 같은 필터 재사용으로 FC 대비 가중치가 수만 배 줄어 과적합·메모리 모두 해결. 결과적으로 적은 데이터로도 학습 가능하고 성능도 좋아집니다.

Q2. ResNet의 잔차연결이 왜 중요한가요?

층이 깊어지면 기울기가 소실·폭발해 학습이 안 됐습니다. ResNet은 블록 출력을 F(x) + x로 바꿔 "입력 그대로를 기본값으로" 두고 변화량 F만 학습하게 했습니다. 역전파에서 기울기가 shortcut을 통해 그대로 뒤로 흐를 수 있어 150층 이상도 안정적으로 학습됩니다. 이 아이디어는 지금도 Transformer 블록(Add & LayerNorm)에 그대로 쓰입니다.

Q3. 2-stage(Faster R-CNN)와 1-stage(YOLO) 디텍터의 차이는?

2-stage는 (1) 영역 제안(RPN) → (2) 각 영역 분류·bbox 보정의 두 단계. 정확도가 높지만 느립니다. 1-stage는 단일 CNN 포워드로 그리드별 bbox와 클래스를 동시에 예측. 빠르지만 작은 객체·밀집 객체에서 상대적으로 약했습니다. 요즘은 YOLOv8~v11, DETR, RT-DETR 같은 1-stage/transformer 기반이 정확도도 거의 따라잡아 산업에선 1-stage가 사실상 기본이 됐습니다.

Q4. ViT는 CNN을 완전히 대체했나요?

데이터와 상황에 따라 다릅니다. 데이터가 적으면 CNN의 귀납 편향(locality) 덕에 여전히 CNN이 유리합니다. JFT-300M 같은 대규모 데이터에선 ViT가 더 잘 스케일합니다. 실무에선 (1) 소규모 사내 데이터는 EfficientNet·ConvNeXt, (2) 대규모 사전학습 백본은 ViT·DINOv2, (3) 실시간 디텍션은 CNN 기반 YOLO 식으로 섞어 씁니다. "완전 대체"가 아니라 "선택지가 늘었다"가 정확합니다.

Q5. CLIP과 멀티모달 LLM(GPT-4V 등)의 차이는?

CLIP은 "이미지와 텍스트의 유사도"만 뽑는 임베딩 모델입니다. zero-shot 분류·검색·텍스트→이미지 가이드에 쓰입니다. 멀티모달 LLM은 이미지를 토큰화해 LLM 컨텍스트에 넣고 "이미지에 대해 자연어로 추론·설명·대화"가 가능합니다. 역할이 다릅니다: 검색·분류는 CLIP, 설명·보고·대화는 멀티모달 LLM. 둘을 함께 쓰는 경우도 많습니다(CLIP으로 top-k 검색 → 멀티모달 LLM으로 설명).

Q6. Diffusion이 GAN을 사실상 대체한 이유는?

GAN은 학습이 불안정(mode collapse, 수렴 어려움)하고 다양성이 떨어졌습니다. Diffusion은 "노이즈 추가의 역과정"을 학습하는 명확한 지도학습 문제라 안정적입니다. CLIP 임베딩으로 텍스트 가이드가 자연스럽게 결합되고, Latent Diffusion(Stable Diffusion)으로 GPU 비용도 극적으로 낮아졌습니다. 품질·안정성·확장성·다양성 모든 면에서 GAN을 앞섰습니다.

Q7. 금융권에서 이미지 AI를 쓸 때 가장 주의할 점은?

(1) 민감정보 유출: 신분증·여권·수표를 외부 API에 보내지 말 것. 사내 모델·사내 LLM만. (2) Deepfake 위변조: 2025년 현재 신분증 사진·셀카가 LLM으로 생성 가능. 라이브니스 검출·PKI 신분증 검증·행동 분석 다층 방어. (3) 차별·편향: 얼굴 인식의 인종·성별 편향. 공정성 테스트. (4) 적대적 공격: 패치 몇 픽셀로 모델 속일 수 있음. 중요 결정엔 사람 확인. (5) 라이선스: YOLO Ultralytics는 AGPL-3.0 → 상용 라이선스 또는 대안 모델 검토. (6) 자동 집행 금지: 비전 모델 결과만으로 계좌 개설·거래 승인 금지, 반드시 사람 확인 게이트.

Q8. OMS 운영자가 이미지/비전 AI로 할 수 있는 가장 가치 있는 일은?

세 가지입니다. (1) 대시보드 스크린샷 → 자연어 요약: 야간에 Grafana/Kibana 캡처를 멀티모달 LLM에 넘겨 "평소와 다른 패턴"을 자연어로 받음 → 사람 깨우기 전 1차 분류. (2) 장애 화면 캡처 분석: 터미널·브라우저 캡처를 Claude Vision에 넣고 과거 매뉴얼 RAG와 결합 → 1차 조치 안내. (3) 리서치/공시 PDF 자동 수집: 차트·테이블 영역 감지 후 LLM이 핵심 수치 요약 → OMS 알림. 모두 "사람 검토 전 1차 가공"에 공통점. 자동 집행은 금지.

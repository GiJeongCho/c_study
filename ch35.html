지도학습: 회귀·분류·앙상블

지도학습은 "입력 X가 주어졌을 때 정답 y를 맞추는" 모델을 데이터로부터 배우는 방법입니다. 수익률 예측(회귀), 부도 여부 판별(분류), 이상거래 탐지(분류) 등 금융 ML의 대부분이 여기에 속합니다. 이 장에서는 선형·로지스틱 회귀부터 의사결정나무, 랜덤포레스트, XGBoost·LightGBM까지 — 캐글과 퀀트 리서치에서 가장 많이 쓰이는 모델들을 "왜 그렇게 작동하는가"의 관점으로 다룹니다.

이 장에서 배울 것

  • 선형회귀의 최소제곱법과 금융에서의 CAPM·팩터모델 연결

  • 의사결정나무의 분할 기준(Gini, Entropy)과 과적합
  • 배깅과 랜덤포레스트의 분산 감소 원리
  • 부스팅(AdaBoost, Gradient Boosting, XGBoost, LightGBM)의 편향 감소 원리
  • SVM과 커널 트릭의 기하학적 직관
  • 퀀트 리서치에서 모델 선택의 실무 기준

35-1회귀·로지스틱·의사결정나무

선형회귀 — 모든 ML의 출발점

선형회귀(Linear Regression)는 "y가 X들의 선형 결합으로 설명된다"고 가정합니다.

y = β₀ + β₁x₁ + β₂x₂ + … + βₚxₚ + ε

계수 β는 최소제곱법(OLS, Ordinary Least Squares)으로 구합니다: 예측값과 실제값의 차(잔차)의 제곱 합을 최소화하는 β를 선택.

CAPM·팩터 모델이 바로 선형회귀

퀀트에서 가장 유명한 모델인 CAPM과 Fama-French 3팩터, 5팩터 모델 모두 본질적으로 선형회귀입니다. CAPM: Rᵢ - Rf = αᵢ + βᵢ(Rm - Rf) + ε — 종목 초과수익률을 시장 초과수익률에 회귀. β는 시장 민감도, α는 "시장이 설명 못 하는 초과수익"입니다. 리서치팀 분석 보고서를 읽을 때 "regression result" 테이블이 나오면 그게 바로 OLS입니다.

다중공선성·L1·L2 정규화 (Ridge, Lasso)

피처 간 상관이 높으면(예: PER과 PBR, EPS 성장률과 매출 성장률) 다중공선성(multicollinearity)이 생겨 계수가 불안정해지고 해석이 어려워집니다. 정규화(regularization)는 계수의 크기에 벌점을 줘서 이 문제를 완화합니다.

이름벌점효과퀀트에서
Ridge (L2)+ λ Σβ²계수 크기 축소, 모두 0에 가깝게다중공선성 완화, 피처 모두 유지
Lasso (L1)+ λ Σ|β|일부 계수를 정확히 0으로 만듦자동 피처 선택, 희소 팩터 모델
Elastic NetL1 + L2 혼합Ridge의 안정성 + Lasso의 희소성피처 많고 상관도 큰 경우

로지스틱 회귀 — 이름은 회귀, 쓰임새는 분류

로지스틱 회귀(Logistic Regression)는 선형 결합의 결과를 시그모이드 함수로 [0, 1] 사이로 짜내서 "확률"로 해석합니다.

P(y=1 | x) = σ(β₀ + β₁x₁ + … + βₚxₚ) = 1 / (1 + e-(β·x))

0.5를 기준으로 둘 중 하나를 선택하면 분류기가 됩니다.

금융 신용평가의 50년 기본기

신용카드사·은행의 전통적 신용평점(credit scoring)이 거의 다 로지스틱 회귀입니다. 피처: 소득, 부채비율, 연체이력, 거래기간 등. 결과: 1년 내 디폴트 확률. 이유: (1) 계수가 "변수당 디폴트 확률에 미치는 영향"으로 해석 가능 — 규제 심사·고객 설명에 유리, (2) 안정적, (3) 데이터 적을 때도 작동. 바젤 규제상 "설명 가능한 모델"이 요구되는 영역에서 여전히 1등 모델입니다.

의사결정나무 (Decision Tree)

의사결정나무는 "스무고개"처럼 질문을 하나씩 던져 데이터를 쪼개 나가는 모델입니다. 각 분기점에서 가장 정보이득이 큰 질문을 선택합니다.

분할 기준:

  • Gini 불순도: 1 - Σpᵢ². 두 클래스가 섞여 있을수록 큼. CART 알고리즘이 사용.
  • Entropy: -Σpᵢ log₂pᵢ. 정보이득 = 분할 전 Entropy - 분할 후 가중 평균 Entropy. ID3·C4.5가 사용.
  • MSE: 회귀 트리에서 분산 감소 기준.

깊이 제한 없는 트리는 반드시 과적합

깊이 제한이 없으면 트리는 학습 데이터의 모든 점을 정확히 외워 버립니다(각 리프노드에 1개 샘플까지 가능). 이러면 학습 100%, 테스트 50%인 모델이 됩니다. max_depth, min_samples_split, min_samples_leaf, ccp_alpha(비용복잡도 가지치기)로 제어해야 합니다. 하지만 혼자 쓰는 단일 트리는 성능이 별로이고, 랜덤포레스트·부스팅과 조합해야 진가가 나옵니다.

35-2랜덤포레스트·부스팅·SVM

앙상블의 두 축: 배깅과 부스팅

랜덤포레스트 (Random Forest)

랜덤포레스트는 배깅의 대표주자입니다. 핵심 두 가지 랜덤성:

  1. 부트스트랩 샘플링: 각 트리는 전체 데이터에서 복원추출한 샘플로 학습(약 63% 사용, 37%는 OOB 샘플).
  2. 랜덤 피처: 각 분기점에서 전체 피처 중 일부만 랜덤 선택해서 그중 최선을 고름(√p 또는 log₂p 개).

이 두 가지가 트리 간 상관을 낮춰, 많은 트리의 "다수결"이 단일 트리보다 훨씬 안정적이게 만듭니다.

OOB(Out-of-Bag) 스코어는 공짜 교차검증

부트스트랩 샘플에 뽑히지 않은 37%의 샘플들로 각 트리를 자동 검증할 수 있습니다. 추가 데이터 분할 없이 CV와 비슷한 성능 추정이 가능해 데이터 적을 때 유용합니다. oob_score=True만 켜면 끝.

Gradient Boosting과 XGBoost / LightGBM — 캐글·퀀트의 지배자

Gradient Boosting은 "직전 모델의 오차(gradient)를 다음 모델이 학습"하는 방식으로 트리를 순차 추가합니다. XGBoost(2014), LightGBM(2016), CatBoost(2017)가 그 발전된 구현체이며, 정형 데이터 ML에서 지난 10년 넘게 왕좌를 지키고 있습니다.

구현트리 성장속도특징
XGBoostLevel-wise(깊이 우선)중간정규화 강함, 산업 표준
LightGBMLeaf-wise(손실 우선)가장 빠름대용량 데이터, 히스토그램 기반
CatBoostOblivious(대칭)중간범주형 자동 처리, 과적합 적음

왜 XGBoost가 알파팩터 조합에 쓰이는가

퀀트 팩터는 보통 수십~수백 개 정도의 수치 피처(밸류·모멘텀·퀄리티·사이즈 등)와 명확한 수치 라벨(미래 수익률)로 이뤄진 "정형 데이터"입니다. 딥러닝은 이미지·텍스트처럼 비정형 데이터에 강하지만, 정형 데이터는 트리 앙상블이 거의 항상 더 좋습니다. 또한 (1) 피처 중요도로 "어떤 팩터가 알파를 만드는지" 해석 가능, (2) 결측 자동 처리, (3) 수백만 행 데이터를 분 단위로 학습 가능 — 리밸런싱 주기에 맞게 재학습하기 좋습니다. 하나증권 리서치가 발표한 알파팩터 모델도 상당수가 XGBoost/LightGBM 기반입니다.

SVM (Support Vector Machine)

SVM은 두 클래스를 가르는 "최대 마진 초평면"을 찾습니다. 두 클래스에서 가장 가까운 샘플들(서포트 벡터)까지의 거리가 최대가 되는 경계선을 선택.

커널 트릭: 데이터가 비선형이면 입력을 고차원으로 매핑해서 선형 분리 가능하게 만듭니다. RBF 커널이 가장 많이 쓰입니다.

SVM은 대용량 데이터에 쓰면 안 된다

SVM의 학습 시간 복잡도는 O(n²)~O(n³)입니다. 10만 행만 넘어가도 몇 시간이 걸립니다. 금융에서 10년치 일봉 전종목 데이터(수백만 행)에는 거의 쓰지 않고, 소규모 데이터·명확한 결정경계·텍스트 분류에서 가끔 씁니다. 요즘은 트리 앙상블이나 신경망에 밀려 거의 안 쓰이지만, "커널 트릭"이라는 발상은 신경망의 "표현학습(representation learning)"으로 이어진 역사적 중요성이 있습니다.

예제 35-1 — 모델 선택 난이도 ★★☆

퀀트팀이 "다음 분기 영업이익이 컨센서스 대비 10% 이상 상회할 확률"을 예측하려 합니다. 데이터: 코스피 상위 300종목 × 20년 분기 데이터(2.4만 행), 피처 80개(재무비율, 모멘텀, 애널리스트 리비전 등). 어느 모델이 1순위일까요? 왜?

정답과 해설 보기

LightGBM이 1순위입니다. 이유: (1) 정형 수치 데이터, (2) 피처 80개로 다중공선성 심할 가능성 — 트리는 이에 강건, (3) 2.4만 행은 중간 규모라 LightGBM이 수초 안에 학습, (4) 재무 데이터는 결측이 흔한데 LightGBM이 자동 처리, (5) 분기별 리밸런싱 주기와 재학습 비용이 맞음. 단, 반드시 TimeSeriesSplit으로 시간 순서 지키고, 애널리스트 데이터의 revision 시점을 point-in-time으로 반영했는지 확인해야 합니다(34장). 2순위는 Lasso(해석용), 3순위는 로지스틱(규제·외부 설명용).

핵심 정리

  • 선형회귀는 모든 ML의 뿌리이자 금융에서는 CAPM·팩터모델 그 자체.
  • 정규화: Ridge(L2)는 계수 축소, Lasso(L1)는 희소 선택, Elastic Net은 혼합.
  • 로지스틱 회귀는 "회귀"지만 분류 — 시그모이드로 확률화. 신용평가 50년 기본.
  • 단일 의사결정나무는 거의 쓰지 않는다. 랜덤포레스트/부스팅의 기본 블록.
  • 배깅(RF)은 분산 감소, 부스팅(XGBoost/LightGBM)은 편향 감소.
  • 정형 데이터 성능 1순위는 LightGBM/XGBoost. 캐글 수상의 70% 이상이 트리 부스팅.
  • SVM은 소규모·텍스트에만 가끔 사용. 대용량에는 금물.

면접 질문

자주 나오는 질문

Q1. Ridge와 Lasso의 수학적·실용적 차이?

Ridge는 β²에 벌점을 줘서 모든 계수를 0 근처로 축소하지만 정확히 0으로 만들지는 않습니다. Lasso는 |β|에 벌점을 줘서 일부 계수를 정확히 0으로 만들어 자동 피처 선택이 됩니다. 수학적으로 Lasso는 미분불가능한 지점(β=0)이 있어 좌표하강법 같은 특수 최적화를 씁니다. 실용적으로는 Ridge는 다중공선성 완화·안정성, Lasso는 희소 모델·피처 선택에 유리합니다.

Q2. 랜덤포레스트가 과적합에 강한 이유는?

두 랜덤성 — 부트스트랩 샘플링과 랜덤 피처 — 이 트리 사이 상관을 낮춥니다. 상관 낮은 많은 분류기의 다수결은 분산이 1/N로 줄어 과적합이 상쇄됩니다(bias-variance tradeoff에서 variance 감소). 또한 각 트리는 서로 다른 샘플/피처를 보므로 특정 노이즈에 공통으로 반응하지 않습니다. 깊은 트리를 많이 써도 전체는 안정적입니다.

Q3. XGBoost와 LightGBM의 핵심 차이?

트리 성장 전략이 다릅니다. XGBoost는 레벨별(level-wise)로 균형 성장, LightGBM은 손실이 가장 크게 줄어드는 리프를 우선 분할(leaf-wise). Leaf-wise는 같은 트리 수로 더 복잡한 패턴 학습 가능하지만 과적합 쉬우니 num_leaves와 min_data_in_leaf 조절이 중요. 속도는 LightGBM이 보통 더 빠르고(히스토그램 기반), 메모리도 적게 씁니다. 성능 자체는 튜닝에 따라 비슷합니다.

Q4. Gradient Boosting이 "gradient"인 이유는?

각 단계에서 "현재까지의 모델이 만든 손실 함수의 음의 기울기(negative gradient)"를 다음 트리가 예측 타깃으로 삼기 때문입니다. 손실이 MSE면 음의 gradient가 그냥 잔차(y - ŷ)라서 "직전 모델의 잔차를 학습"이라는 설명이 성립합니다. 다른 손실함수(logloss 등)에서도 같은 원리를 일반화한 것이 Gradient Boosting입니다.

Q5. 피처 중요도(feature importance)만 믿어도 되나요?

안 됩니다. 트리 기반 중요도는 (1) 상관 높은 두 피처가 있으면 중요도가 "임의로" 한쪽에 쏠리고, (2) 카디널리티 높은 범주형이 과대평가되며, (3) 데이터셋에 특화된 값입니다. 더 신뢰할 수 있는 방법은 Permutation Importance(피처를 섞어서 성능 하락 측정)와 SHAP(37장에서 다룸)입니다.
